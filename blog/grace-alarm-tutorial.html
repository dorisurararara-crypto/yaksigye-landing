약시계 grace 알림 설정 방법
복약 60분 알림 완전 가이드

약시계의 핵심 기능인 grace 알림은, 부모님이 약을 드셔야 할 시간 이후 60분 안에 버튼을 누르지 않으면 자녀에게 자동으로 알림을 보내는 기능입니다.

grace 알림이란?

복약 예정 시간이 됐다고 바로 알림이 가면 부담스러울 수 있습니다. "잠깐 미뤄도 된다"는 여유(grace period) 60분을 두고, 그 안에도 인증이 없을 때 자녀에게 알립니다. 진짜 누락과 단순 미루기를 구분하는 게 포인트입니다.

설정 방법 (3단계)

1
자녀용 앱에서 복약 시간 등록

자녀용 앱 → 약 관리 → "약 추가" → 복약 시간(예: 아침 8시, 저녁 7시) 입력

2
알림 수신 허용 확인

자녀 폰 설정 → 앱 → 약시계 자녀용 → 알림 → "허용"

부모님 폰도 동일하게 알림 허용 확인

3
페어링 상태 확인

자녀용 앱 홈 화면에서 부모님 이름 옆 "연결됨" 표시 → grace 알림 활성화 완료

팁: 부모님이 "약 먹었어요" 버튼을 눌렀는데 알림이 왔다면? late tap(늦은 인증) 기능으로 자녀 앱에서 "확인했어요"를 누르면 알림이 해제됩니다.

3일 연속 누락 시 격상 알림

grace 60분이 지나도 인증이 없는 날이 3일 연속 감지되면, 긴급 격상 알림과 함께 병원 방문 권고 메시지가 자녀에게 발송됩니다.

자주 묻는 질문

  • 알림이 안 와요: 자녀 폰의 알림 설정 확인 → 배터리 절전 모드 예외 추가
  • grace 시간을 바꿀 수 있나요: v1.1에서 30분·60분·90분 선택 예정 (현재는 60분 고정)
  • 부모님이 실수로 눌렀어요: 자녀 앱에서 해당 복약 이력 정정 가능 (2시간 이내)
